- **URL**: https://www.ntia.gov/report/2021/minimum-elements-software-bill-materials-sbom
- **标题**: The Minimum Elements For a Software Bill of Materials (SBOM)
- **发布方**: NTIA（美国商务部国家电信和信息管理局）
- **发布日期**: 2021-07-12
- **抓取日期**: 2026-09-18
- **来源层级**: 官方文档（政府报告）

## 关键摘录 / 事实点

1. 直接背景："The Executive Order (14028) on Improving the Nation's Cybersecurity directs the Department of Commerce, in coordination with NTIA, to publish the 'minimum elements' for a Software Bill of Materials (SBOM)."
2. SBOM 定义原文："a **formal record** containing the details and **supply chain relationships** of various components used in building software."
3. 报告建立在 NTIA 自 2018 年起的 SBOM 多方利益相关者进程之上。
4. 报告定义的三类最小要素（细节见报告正文）：Data Fields（供应商名、组件名、组件版本、其他唯一标识符如 purl/CPE、依赖关系、SBOM 作者、时间戳）、Automation Support（SPDX/CycloneDX/SWID 三种格式）、Practices and Processes。

## 支撑报告中的结论

- §10 SBOM 为什么出现（EO 14028 政策链）
- §10 SBOM 包含什么（NTIA 最小要素清单）
- §10 SBOM ≠ SCA 论证的官方依据（SBOM 是"记录"不是"分析"）
