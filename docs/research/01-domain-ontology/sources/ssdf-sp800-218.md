- **发布方**: NIST（作者含 Karen Scarfone、Donna Dodson 等）
- **发布日期**: 2022-02
- **抓取日期**: 2026-09-18
- **来源层级**: 官方文档（NIST 特别出版物）

## 关键摘录 / 事实点

1. 定位：SSDF 是"可集成进任何 SDLC 的核心安全软件开发实践集合"，目标：减少发布软件中的漏洞数量、减轻未发现漏洞被利用的影响、根治漏洞成因。
2. 它提供安全开发的**共同词汇**，供采购方与供应商沟通使用。
3. SSDF 是 EO 14028 Section 4 的核心交付物之一（见 [nist-eo-14028.md](nist-eo-14028.md)）。
4. 实践分组（文档正文）：Prepare the Organization (PO) / Protect the Software (PS) / Produce Well-Secured Software (PW) / Respond to Vulnerabilities (RV)。
