## 关键摘录 / 事实点

1. EO 14028 于 2021-05-12 发布，Section 4 要求 NIST 牵头制定软件供应链安全标准/工具/最佳实践，联邦采购据此执行。
2. NIST 于 2021-06-26 前（会商 NSA/OMB/CISA/DNI）定义了 **"critical software"**；2021-07-11 前发布 critical software 安全措施指南与厂商源码测试最低标准。
3. 后续产出：2021-11 初步供应链安全指南；2022-02 增补实践指南（即 SSDF 更新）；消费者 IoT/软件标签计划标准。
4. 注：federalregister.gov 的 EO 原文页有反爬限制未能直接抓取；EO→SBOM 的指令链由 NTIA 官方页面佐证（见 [ntia-sbom-minimum-elements.md](ntia-sbom-minimum-elements.md)）。
