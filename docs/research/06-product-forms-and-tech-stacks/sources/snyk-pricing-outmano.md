## 关键事实点

- Snyk 按 **contributing developer（贡献代码的开发者席位）** 计费；且 Open Source / Code / IaC / Container 各产品线**分别计价**，账单 = 席位 × 启用的产品组合。
- 公开价：Free $0；Team $25/席/月（10 席上限）；Ignite $105/席/月（≈$1,260/席/年）；Enterprise 询价。
- 自托管仅 Enterprise 档提供（第三方对比表口径）。

## 支撑报告结论

- "开发者平台型 SSCS"形态的典型定价包装 = per-dev × per-product-line。
- 与 Endor Labs 的 per-contributor/年 模式互为印证：开发者平台型物种全部收敛到席位计费。
