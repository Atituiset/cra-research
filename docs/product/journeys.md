# 统一产品旅程

当前目标用户为产品安全负责人；交付单位是可定位到制品的产品发布物。

| 旅程 | 当前入口 | 当前输出 |
|---|---|---|
| 产品接入 | 导入已有签名 PoC 证据包 | Release、证据与待复核判定 |
| 漏洞研判 | 静态页面查证据，CLI review | 有效判定与不可变复核记录 |
| 情报变化 | CLI reassess 显式触发 | 新调查中修订，历史保持 |
| 修复复核 | 导入新制品证据，CLI verify-fix | 验证记录与 fixed 候选 |
| 事件报告 | CLI incident、record-report | 冻结快照、期限与外部回执记录 |
| 客户应答 | CLI export | 带完整文件索引的内部复核包 |

采用 B 的五个 Journey 作为产品流程参考，使用 A 的真实数据和签名作为输入。当前静态 UI 不提供在线操作；所有状态通过共享核心计算。正式客户交付所需认证、标准签发和原始证据完整性仍在实施设计待续范围。
